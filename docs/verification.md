# Verification

TL;DR: for anyone checking a claim in these docs: each row states what one primary source proves, so you can rerun the test or reread the line yourself.
Other docs cite rows as (verification: Vn); a load-bearing claim with no row is marked [unverified] where it is stated.

## How to read and add rows

Source shorthand:
- **T22** is `solana-program/token-2022` at commit `45b91ca` (main, read 2026-09-25). `t22/processor.rs` is `program/src/processor.rs`; `ct/processor.rs` is `program/src/extension/confidential_transfer/processor.rs`.
- **agave** is `anza-xyz/agave` at commit `b8c619a` (master, read 2026-09-25).
- **SIMD-0385** is `solana-foundation/solana-improvement-documents` `proposals/0385-transaction-v1.md` at `05f2ae9`.
- **RPC** means public mainnet-beta and devnet endpoints on the date given.
- **CU** is compute units. Measurements run in LiteSVM 0.16.0 unless a row says otherwise.
- Test names are functions in this repo (`grep -rn "fn <name>" programs crates cli`); program tests are under `programs/scope/tests/it/`.

To add a row: take the next unused id (the highest today is V92), put it in the section its source belongs to, state only what the source proves, and cite a file and line in a named version or commit, an RPC read with its date, or a test name. Ids are never renumbered or reused. When newer numbers replace a row's, the old row keeps its id and says "Superseded by Vn", so existing cites still resolve. Line numbers drift; when bumping a pinned version, recheck the rows that name it.
